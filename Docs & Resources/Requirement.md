## Requirements

This project uses several Python libraries for data cleaning, exploratory data analysis, data visualization, preprocessing, and machine learning. These dependencies are listed in the `requirements.txt` file so that anyone working with the project can install the necessary packages and reproduce the analysis.

The main libraries used in this project are:

* **Pandas** — for loading, cleaning, and manipulating the forest fire dataset.
* **NumPy** — for numerical calculations and data transformations.
* **Matplotlib** — for creating data visualizations and graphs.
* **Seaborn** — for statistical visualizations, including distributions, scatterplots, and correlation heatmaps.
* **Scikit-learn** — for data preprocessing, unsupervised learning, supervised machine learning, and model evaluation.
* **Jupyter** — for creating and running the project notebooks.

### requirements.txt

```txt
pandas
numpy
matplotlib
seaborn
scikit-learn
jupyter
```

These packages can be installed by running:

```bash
pip install -r requirements.txt
```
